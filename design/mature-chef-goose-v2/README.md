# Mature Chef Goose voice agent v2

Review files for the six-state mature Chef Goose voice agent.

- `mature-chef-goose-v2-preview.html` is a self-contained interactive preview. Open it directly in a browser; no server or build step is required.
- `mature-chef-goose-v2.zip` contains transparent PNGs, animated WebP files, PNG sprite sheets, posters, the interactive UI, a React component, timing manifest, and documentation.

States: Idle, Listening, Thinking, Speaking, Warning, and the UI-only Hover greeting. Hovering or focusing the goose reveals the three egg controls. The transparent bridge and delayed close keep the controls available while the pointer travels from the goose to the eggs.
