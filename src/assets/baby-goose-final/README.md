# Baby goose approved-design posture set

16 standalone white-background PNG illustrations. This is the revised set based on the approved `goose-g2-up-next-final-tuft.png` character: smaller head, compact belly, smooth neck transition and two low backward-swept white-filled feather tips.

- `png/`: all 16 poses; each 1254 × 1254, opaque RGB.
- `preview.html`: full-size overview plus 32px and 64px samples.
- `baby-goose-final.zip`: portable PNGs and preview.
- `qa/contact.jpg`: contact sheet.

G2 reuses the approved artwork. G8y is an exact horizontal mirror of G8x. Hats cover the tuft on Toque; the head stays tucked in the sleeping pose. These are static posture illustrations, not animation loops. White backgrounds retain slight image-generation colour variation; they are not transparent.

The former `baby-goose-postures/` and experimental `baby-goose-postures-v2/` are retained separately. Use this directory for the approved-design set.
